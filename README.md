# Frmework

Frmework is a web application that displays a dynamic gallery of images fetched from a public API. Built with **HTML**, **CSS**, and **vanilla JavaScript**, it allows users to explore, like, and comment on photos in an interactive interface inspired by modern image platforms.

## Features

- Dynamic image gallery – Images are fetched from the [Image Feed API](https://image-feed-api.vercel.app/) and displayed dynamically using JavaScript.  
- Interactive elements – Hover effects, like and comment functionality for each image.  
- Load more button – Fetches and displays additional images on demand, providing a simple form of pagination.  
- Loading states – Visual feedback while images are being fetched.  
- Error handling – Handles failed image loads and comment submissions with user-friendly messages.  
- Top likes leaderboard – Displays the top three most liked images with links to their respective posts. Shows basic stats such as total images, total comments and total likes.
- Responsive design – Works smoothly across desktop and mobile screens.  
- Like, comment, and image counters – Displays real-time counts for user interactions.

## Technologies Used

- **HTML** – Structure and layout  
- **CSS** – Styling and responsive design  
- **JavaScript (Vanilla)** – API fetching, interactivity, and dynamic data handling  

## Getting Started

### Prerequisites
Ensure that **Node.js** is installed on your system.

### Installation
1. Clone this repository:   
    git clone <https://github.com/siritell/The-Fundamentals---JavaScript.git>

2. Install dependencies (if any):
    npm install

3. Start the development server:
    npm run dev

4. Open your browser and go to the address shown in your terminal.
